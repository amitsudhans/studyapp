§ 1.1 Foundation & Cartesian Product

Introduction to Relations in Mathematics

In everyday language, a relation describes a recognizable link between two entities. In mathematics, we abstract this rigorously: a Relation R from set A to set B is defined simply as an arbitrary subset of the Cartesian Product A × B.

"There is no permanent place in the world for ugly mathematics... It may be very hard to define mathematical beauty, but that does not prevent us from recognising one when we read it."

— A Mathematician's Apology

2. R₂ = {(a, b) ∈ A × B : age(a) > age(b)}
3. R₃ = {(a, b) ∈ A × B : a lives in same locality as b}
Notation: If (a, b) ∈ R, we write a R b ("a is related to b").

§ 1.2 Extreme Cases • Trivial Relations

Empty Relation (φ) & Universal Relation (A × A)

Since any relation in set A is a subset of A × A, the two extreme subsets are the empty set φ and the full Cartesian product A × A.

🚫 Definition 1

Empty Relation (R = φ)

A relation R in set A is called an empty relation if no element of A is related to any element of A, i.e., R = φ ⊂ A × A.

🏫 Example 1 (Boys School):

Let A = all students in a boys' school.
Relation R = {(a, b) : a is sister of b}.
Since no student is female, no pair satisfies the condition: R = φ.

🌐 Definition 2

Universal Relation (R = A × A)

A relation R in set A is called a universal relation if each element of A is related to every element of A, i.e., R = A × A.

📏 Example 1 (Height Difference):

Let A = all students in a boys' school.
Relation R' = {(a, b) : |height(a) - height(b)| < 3 meters}.
Since human heights differ by at most ~1.5m, every pair satisfies this: R' = A × A.

💡 Both the empty relation and the universal relation are often called trivial relations.
§ 1.2 Definition 3 • Three Core Pillars

Reflexive, Symmetric, and Transitive Relations

The foundation of advanced algebra is built upon these three structural properties of a relation R in a set A.

🪞 Pillar 1

Reflexive

(a, a) ∈ R, ∀ a ∈ A

Every element must be related to itself. Self-loops must exist for all elements of set A without exception.

🔄 Pillar 2

Symmetric

(a₁, a₂) ∈ R ⇒ (a₂, a₁) ∈ R

If an arrow goes from a₁ to a₂, there must be a return arrow from a₂ to a₁. Two-way street property.

🔗 Pillar 3

Transitive

(a, b) ∈ R & (b, c) ∈ R ⇒ (a, c) ∈ R

If a is linked to b, and b is linked to c, then a must bypass b and link directly to c. Shortcut principle.

⚠️ Textbook Example 4 Analysis: A = {1, 2, 3} R = {(1,1), (2,2), (3,3), (1,2), (2,3)}
✓ Reflexive? YES!

(1,1), (2,2), and (3,3) are all present in R.

✕ Symmetric? NO!

(1, 2) ∈ R, but the reverse (2, 1) ∉ R.

✕ Transitive? NO!

(1, 2) ∈ R and (2, 3) ∈ R, but (1, 3) ∉ R.

§ 1.2 Definition 4 • The Holy Trinity

Equivalence Relations: Geometric & Arithmetic Proofs

A relation R is an Equivalence Relation if and only if it is Reflexive, Symmetric, and Transitive simultaneously.

📐 Example 2: T₁ ≅ T₂ (Congruence)

Reflexive: Every triangle is congruent to itself: T₁ ≅ T₁.

Symmetric: If T₁ ≅ T₂, then T₂ ≅ T₁.

Transitive: If T₁ ≅ T₂ and T₂ ≅ T₃, then T₁ ≅ T₃.

Result: Equivalence Relation
⟂ Example 3: L₁ ⊥ L₂ (Perpendicular)

Not Reflexive: A line cannot be perpendicular to itself (L₁ ∦ L₁ ⊥ L₁).

Symmetric: If L₁ ⊥ L₂, then L₂ ⊥ L₁ (True!).

Not Transitive: If L₁ ⊥ L₂ and L₂ ⊥ L₃, then L₁ is parallel to L₃, not perpendicular!

Result: Symmetric ONLY
🔢 Example 5: 2 divides a – b in ℤ

Reflexive: a – a = 0 is divisible by 2 for all a ∈ ℤ.

Symmetric: If 2 | (a – b), then 2 | -(a – b) = (b – a).

Transitive: a – c = (a – b) + (b – c). Sum of two evens is always even!

Result: Equivalence Relation in ℤ
§ 1.2 Equivalence Classes [a] & Partitioning

Equivalence Classes: Partitioning Sets into Disjoint Boxes

Every equivalence relation R in set X divides X into mutually disjoint subsets called equivalence classes [a] whose union equals X.

1. Internal Affinity All elements in Aᵢ are related to each other.
2. Mutual Isolation No element of Aᵢ is related to any element of Aⱼ (i ≠ j).
3. Complete Cover ∪ Aⱼ = X and Aᵢ ∩ Aⱼ = φ for all i ≠ j.

§ 1.3 Definition 5 • Injective Functions

One-One (Injective) vs Many-One Functions

A function f: X → Y is one-one (injective) if images of distinct elements of X are distinct. That is: f(x₁) = f(x₂) ⇒ x₁ = x₂. Otherwise, f is many-one.

Key Textbook Examples:

Example 8: f: ℕ → ℕ, f(x) = 2x

2x₁ = 2x₂ ⇒ x₁ = x₂. One-one! But odd numbers (1, 3, 5...) in ℕ have no pre-images, so it is NOT onto.

Example 11: f: ℝ → ℝ, f(x) = x²

f(-1) = 1 = f(1). Since distinct inputs share the same output, f is MANY-ONE. Also negative numbers have no real pre-image, so NOT onto.

§ 1.3 Definitions 6 & 7 • Surjective & Bijective

Onto (Surjective) & Bijective (One-One & Onto)

A function f: X → Y is onto (surjective) if Range(f) = Co-domain(Y). That is, for every y ∈ Y, there exists x ∈ X such that f(x) = y. When f is both one-one and onto, it is called Bijective.

Example 9

f: ℝ → ℝ given by f(x) = 2x

One-One: f(x₁) = f(x₂) ⇒ 2x₁ = 2x₂ ⇒ x₁ = x₂.

Onto: For any real y ∈ ℝ, choose x = y / 2. Then f(y/2) = 2(y/2) = y.

✓ Both One-One and Onto ⇒ BIJECTIVE!
Theorem on Finite Sets

Pigeonhole Property on Finite Sets

For any finite set X, a function f: X → X is:

f is One-One ⟺ f is Onto
If 3 distinct elements map to 3 elements, all must be covered! (Notice: False for infinite sets like ℕ or ℝ).
Example 12 (Piecewise Swap on ℕ): f(x) = x + 1 (if x is odd) and x – 1 (if x is even)

§ 1.4 Definition 8 • Composition Pipeline

Composition of Functions: gof and fog

Let f: A → B and g: B → C be two functions. The composition gof: A → C is defined by: gof(x) = g(f(x)), ∀ x ∈ A.

Example 16: Demonstrating gof ≠ fog Let f(x) = cos x, g(x) = 3x²
gof(x) = g(f(x))

= g(cos x)

= 3(cos x)² = 3 cos²x

fog(x) = f(g(x))

= f(3x²)

= cos(3x²)

⚠️ Notice at x = 0: gof(0) = 3(1)² = 3, while fog(0) = cos(0) = 1. Hence gof ≠ fog in general!
§ 1.4 Definition 9 • Inverses

Invertible Functions & Deriving f⁻¹

A function f: X → Y is invertible if there exists a function g: Y → X such that: gof = I_X and fog = I_Y. The function g is called the inverse of f (f⁻¹).

Golden Theorem:

A function f is invertible if and only if f is one-one and onto (bijective)!

This provides a direct method: to prove invertibility, simply prove injectivity and surjectivity.
Example 17 Derivation: f(x) = 4x + 3

Step 1: Set y = 4x + 3

Step 2: Solve for x in terms of y: x = (y – 3) / 4

Step 3: Define g(y) = (y – 3) / 4

Step 4: Check gof(x) = g(4x + 3) = (4x + 3 – 3)/4 = 4x/4 = x = I_N(x)

Step 5: Check fog(y) = f((y – 3)/4) = 4((y – 3)/4) + 3 = y – 3 + 3 = y = I_Y(y)

✓ Hence, f is invertible and f⁻¹(y) = (y – 3) / 4.

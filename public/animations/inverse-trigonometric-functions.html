§ 2.1 The Invertibility Dilemma

Why Invert Trigonometric Functions?

In Chapter 1, we learned that a function f has an inverse f⁻¹ if and only if it is bijective (one-one and onto). However, natural trigonometric functions are periodic (repeating indefinitely), meaning they are naturally many-to-one over ℝ!

✨ Felix Klein on Mathematical Science

"Mathematics, in general, is fundamentally the science of self-evident things."

— Famous 19th Century Geometer

⚠️ The Fundamental Problem:

Consider sin 0 = sin π = sin 2π = 0. Because infinitely many distinct inputs produce the same output, the horizontal line test fails everywhere on ℝ.

sine: ℝ → [-1, 1] (Periodic with period 2π)
cosine: ℝ → [-1, 1] (Periodic with period 2π)
tangent: ℝ - {(2n+1)π/2} → ℝ (Period π)

✂️ The Solution: Branch Truncation

By restricting the domain to a custom contiguous interval where the function is strictly monotonic (always increasing or decreasing), it becomes one-one and onto with its full range!

Crucial in Calculus: Inverse trigonometric functions serve to evaluate essential anti-derivatives like ∫ 1/√(1 - x²) dx = sin⁻¹x + C and ∫ 1/(1 + x²) dx = tan⁻¹x + C.
§ 2.2 Arcsine & Principal Branch

Inverse Sine Function (sin⁻¹x / arc sine)

Restricting the domain of sine to the closed interval [-π/2, π/2] makes it strictly increasing, one-one, and onto with range [-1, 1].

Principal Value Definition
sin⁻¹ : [-1, 1] → [-π/2, π/2]
Domain: [-1, 1] • Range: [-π/2, π/2]

While other intervals like [-3π/2, -π/2] or [π/2, 3π/2] are also bijective branches, the branch with range [-π/2, π/2] is universally designated as the Principal Value Branch.

⚠️ Warning: sin⁻¹x must NEVER be confused with (sin x)⁻¹ = 1 / sin x = cosec x!
Cancellation Identities:
1. sin(sin⁻¹ x) = x Valid for all numbers x in the domain [-1, 1].
2. sin⁻¹(sin x) = x Valid ONLY when angle x lies within [-π/2, π/2]!
Odd Symmetry: Because sine is odd, sin⁻¹(-x) = -sin⁻¹(x) for all x ∈ [-1, 1].
§ 2.2 Geometric Remark (Fig 2.1)

Graphs: Mirror Reflection along the Line y = x

If (a, b) lies on the graph of y = sin x, then by definition of inverse functions, (b, a) must lie on the graph of y = sin⁻¹ x. Geometrically, the inverse graph is obtained by reflecting the original curve across the 45° diagonal line y = x.

y = sin x y = sin⁻¹ x y = x (Mirror)
Key Coordinate Inversion:
sin(0) = 0 → sin⁻¹(0) = 0
sin(π/6) = 0.5 → sin⁻¹(0.5) = π/6
sin(π/2) = 1 → sin⁻¹(1) = π/2
sin(-π/2) = -1 → sin⁻¹(-1) = -π/2
§ 2.2 Arccosine & The [0, π] Principal Branch

Inverse Cosine Function (cos⁻¹x)

Unlike sine, the cosine function cannot be restricted to [-π/2, π/2] because cos(-x) = cos(x) (even function). To make it bijective, its domain is restricted to [0, π] where it decreases monotonically from 1 down to -1!

Definition

cos⁻¹ : [-1, 1] → [0, π]

Domain is [-1, 1] and Range (Principal Value Branch) is [0, π].

Other bijective intervals: [-π, 0], [π, 2π].
The π – θ Rule

cos⁻¹(–x) = π – cos⁻¹(x)

Since the range of cos⁻¹ is strictly non-negative [0, π], negative inputs map to Quadrant II:

cos⁻¹(-1/2) = π – π/3 = 2π/3
Cancellation Rules
cos(cos⁻¹ x) = x, ∀ x ∈ [-1, 1]
cos⁻¹(cos x) = x, ∀ x ∈ [0, π]
§ 2.2 Open Interval Branches

Inverse Tangent (tan⁻¹x) & Cotangent (cot⁻¹x)

Because tangent has vertical asymptotes at odd multiples of π/2 and cotangent at multiples of π, their principal branches use open intervals!

📈 tan⁻¹x

tan⁻¹ : ℝ → (–π/2, π/2)

  • • Domain: Entire real line ℝ = (–∞, ∞)
  • • Range: Open interval (–π/2, π/2)
  • • Odd Symmetry: tan⁻¹(–x) = –tan⁻¹(x)
  • • Example: tan⁻¹(–√3) = –π/3, tan⁻¹(1) = π/4
📉 cot⁻¹x

cot⁻¹ : ℝ → (0, π)

  • • Domain: Entire real line ℝ = (–∞, ∞)
  • • Range: Open interval (0, π)
  • • Negative Rule: cot⁻¹(–x) = π – cot⁻¹(x)
  • • Example 2: cot⁻¹(–1/√3) = π – π/3 = 2π/3
§ 2.2 Split Domain & Singular Points

Inverse Cosecant (cosec⁻¹x) & Secant (sec⁻¹x)

Since cosecant and secant assume values $|y| \ge 1$, their domains exclude the interior interval (–1, 1), and their ranges omit singular asymptote angles.

cosec⁻¹x

cosec⁻¹ : ℝ – (–1, 1) → [–π/2, π/2] – {0}

Because sin 0 = 0, cosec 0 is undefined. Hence {0} is excluded from the principal value branch.

cosec⁻¹(2) = π/6 • cosec⁻¹(–√2) = –π/4
sec⁻¹x

sec⁻¹ : ℝ – (–1, 1) → [0, π] – {π/2}

Because cos(π/2) = 0, sec(π/2) is undefined. Hence {π/2} is excluded from the principal value branch.

sec⁻¹(2/√3) = π/6 • sec⁻¹(–2) = π – π/3 = 2π/3
§ 2.2 Master Textbook Summary Table

Domains and Principal Value Branches of All 6 Functions

Memorize this table: whenever an inverse trigonometric function is evaluated without mentioning a specific branch, it always refers to the Principal Value Branch.

Function Domain Range (Principal Value Branch) Negative Rule
y = sin⁻¹ x [–1, 1] [–π/2, π/2] sin⁻¹(–x) = –sin⁻¹ x
y = cos⁻¹ x [–1, 1] [0, π] cos⁻¹(–x) = π – cos⁻¹ x
y = tan⁻¹ x ℝ (–π/2, π/2) tan⁻¹(–x) = –tan⁻¹ x
y = cot⁻¹ x ℝ (0, π) cot⁻¹(–x) = π – cot⁻¹ x
y = sec⁻¹ x ℝ – (–1, 1) [0, π] – {π/2} sec⁻¹(–x) = π – sec⁻¹ x

§ 2.3 The Classic Board Exam Trap

Beware the Cancellation Identity Trap!

Many students mistakenly write sin⁻¹(sin θ) = θ blindly! This is ONLY true if θ lies within the principal value branch!

Example: sin⁻¹(sin 2π/3)
✕ Wrong: 2π/3 (∉ [–π/2, π/2])
sin(2π/3) = sin(π – π/3) = sin(π/3)
✓ Correct Answer: π/3
Example: cos⁻¹(cos 7π/6)
✕ Wrong: 7π/6 (∉ [0, π])
cos(7π/6) = cos(2π – 5π/6) = cos(5π/6)
✓ Correct Answer: 5π/6
Example: tan⁻¹(tan 3π/4)
✕ Wrong: 3π/4 (∉ (–π/2, π/2))
tan(3π/4) = tan(π – π/4) = –tan(π/4)
✓ Correct Answer: –π/4
§ 2.3 & Historical Note

Algebraic Properties & Ancient Indian Heritage

The study of trigonometry originated in ancient India before traveling to Arabia and Europe. The Sanskrit term jya (half-chord) gave rise to the Latin sinus (sine).

Key NCERT Simplifications:
3 sin⁻¹ x = sin⁻¹(3x – 4x³) [Put x = sin θ]
3 cos⁻¹ x = cos⁻¹(4x³ – 3x) [Put x = cos θ]
sin(tan⁻¹ x) = x / √(1 + x²) [Right Triangle Model]
Historical Timeline from Textbook:

• Aryabhata (476 A.D.): First calculated tables of sine (*ardha-jya*) in the *Aryabhatiya*.

• Bhaskara I (600 A.D.): Formula to find sine values for angles > 90°.

• Yuktibhasa (16th c. Kerala School): Contains early geometric proof for the expansion of sin(A + B).

• Sir John F.W. Herschel (1813): Introduced the notation sin⁻¹x, cos⁻¹x for arc sine and arc cosine.

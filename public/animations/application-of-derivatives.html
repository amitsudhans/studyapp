Rate of Change of Quantities: The Core Calculus Concept

"With Calculus as a key, Mathematics can be successfully applied to the explanation of the course of Nature." — Alfred North Whitehead. When one quantity $y$ varies with another quantity $x$ under a rule $y = f(x)$, the derivative $\frac{dy}{dx}$ (or $f'(x)$) represents the instantaneous rate of change of $y$ with respect to $x$. At a specific point $x_0$, $\left.\frac{dy}{dx}\right|_{x=x_0}$ is the rate at that exact instant.

🔄 The Parametric Time-Rate Chain Rule

If two variables $x$ and $y$ are both varying with respect to time $t$, i.e. $x = f(t)$ and $y = g(t)$, then by the Chain Rule:

\frac{dy}{dx} = \frac{dy / dt}{dx / dt}  \text{(provided } \frac{dx}{dt} \neq 0\text{)}
Classic Examples from Textbook:
• Example 1: Area of circle $A = \pi r^2 \implies \frac{dA}{dr} = 2\pi r$. When $r = 5\text{ cm}$, rate is $10\pi\text{ cm}^2/\text{s}$.
• Example 2: Cube volume $V = x^3 \implies \frac{dV}{dt} = 3x^2 \frac{dx}{dt} = 9 \implies \frac{dx}{dt} = \frac{3}{x^2}$. Surface area $S = 6x^2 \implies \frac{dS}{dt} = 12x \frac{dx}{dt} = \frac{36}{x} = 3.6\text{ cm}^2/\text{s}$ at $x = 10\text{ cm}$.
• Example 3: Circular lake ripple with $\frac{dr}{dt} = 4\text{ cm/s}$. When $r = 10\text{ cm}$, $\frac{dA}{dt} = 2\pi r \frac{dr}{dt} = 80\pi\text{ cm}^2/\text{s}$.

§ 6.2 Applied Rates Economics & Physical Constraints

Marginal Economics & Geometric Mechanics

Derivatives connect real-world fiscal decisions with mechanical motion. In business, Marginal Cost ($MC$) and Marginal Revenue ($MR$) measure instantaneous change per unit item. In physics, rigid bodies like sliding ladders couple rates through geometric constraints.

💰 Marginal Cost & Marginal Revenue

Definitions:
• Marginal Cost: MC = \frac{dC}{dx}  [Instantaneous cost of output x]
• Marginal Revenue: MR = \frac{dR}{dx}  [Instantaneous revenue of output x]
Example 5 (Marginal Cost): For $C(x) = 0.005x^3 - 0.02x^2 + 30x + 5000$:
$MC = \frac{dC}{dx} = 0.015x^2 - 0.04x + 30$.
When $x = 3$: $MC = 0.015(9) - 0.04(3) + 30 = 30.015 \approx \mathbf{₹ 30.02}$.

🪜 Exercise 6.1 Q10: Leaning Ladder on Wall

A 5 m ladder leans against a wall. The bottom slides away at $\frac{dx}{dt} = 2\text{ cm/s}$. How fast does the height $y$ drop when $x = 4\text{ m}$?

1. Constraint: x² + y² = 5² = 25
2. Differentiate w.r.t t: 2x(dx/dt) + 2y(dy/dt) = 0
3. When x = 4 m: y = √(25 - 16) = 3 m
4. 2(4)(2) + 2(3)(dy/dt) = 0 ⟹ dy/dt = -16/6 = -8/3 cm/s
The height drops at 8/3 cm/s! (Negative sign indicates decreasing height).

Exercise 6.1 Q14: Leaking Sand Cone

Sand poured at $12\text{ cm}^3/\text{s}$ forms a cone where height is always one-sixth of radius: $h = r/6 \implies r = 6h$.

V = \frac{1}{3}\pi r^2 h = \frac{1}{3}\pi (6h)^2 h = 12\pi h^3

§ 6.3 Monotonicity Definitions & Parabola x² Sign Behavior

Increasing and Decreasing Functions: Analytical Definitions

Let $I$ be an interval contained in the domain of a real-valued function $f$. We formally classify whether moving from left to right along the graph causes the height to rise, fall, or stay constant.

Strictly Increasing

x₁ < x₂ ⟹ f(x₁) < f(x₂)

Curve constantly ascends; no flat plateaus permitted!

Strictly Decreasing

x₁ < x₂ ⟹ f(x₁) > f(x₂)

Curve constantly descends from left to right.

Constant Function

f(x) = c  ∀ x ∈ I

A completely horizontal flat line; slope is zero everywhere.

The Parabola Archetype: f(x) = x² (Fig 6.1)

Left of Origin (x < 0):
• Moving left to right (e.g. -2 to -1): f(-2) = 4, f(-1) = 1.
• Height decreases ⟹ f is strictly decreasing on (-∞, 0).
Right of Origin (x > 0):
• Moving left to right (e.g. 1 to 2): f(1) = 1, f(2) = 4.
• Height increases ⟹ f is strictly increasing on (0, ∞).

6.3 Theorem 1: First Derivative Test for Monotonicity

Part - 1

§ 6.3 Theorem 1 Mean Value Theorem Connection

First Derivative Test for Monotonicity

Theorem 1 provides the ultimate calculus criterion for determining growth or decay using the sign of the tangent slope $f'(x)$.

Theorem 1 Statement & Proof

Let $f$ be continuous on $[a, b]$ and differentiable on $(a, b)$:

  • • f'(x) > 0 ∀ x ∈ (a, b) ⟹ f is strictly increasing on [a, b]
  • • f'(x) < 0 ∀ x ∈ (a, b) ⟹ f is strictly decreasing on [a, b]
  • • f'(x) = 0 ∀ x ∈ (a, b) ⟹ f is constant on [a, b]
Proof Sketch via MVT: For $x_1 < x_2$, there exists $c \in (x_1, x_2)$ such that: $$f(x_2) - f(x_1) = f'(c)(x_2 - x_1)$$ Since $x_2 - x_1 > 0$, the sign of $f(x_2) - f(x_1)$ is identical to the sign of $f'(c)$!

Example 8: f(x) = x³ - 3x² + 4x on ℝ

f'(x) = 3x² - 6x + 4
      = 3(x² - 2x + 1) + 1
      = 3(x - 1)² + 1
Since 3(x - 1)² ≥ 0, f'(x) ≥ 1 > 0 for all x ∈ ℝ!
⟹ f(x) is strictly increasing everywhere on the real line.

§ 6.3 Trigonometric Monotonicity Quadrant Analysis & Periodic Swings

Monotonicity of Trigonometric Functions

Trigonometric functions change sign as angles traverse different quadrants. A classic board exam pitfall is declaring a function "increasing" over an interval where it oscillates both up and down!

Example 9: f(x) = cos x on (0, 2π)

f'(x) = -sin x

• Interval (0, π): $\sin x > 0 \implies f'(x) < 0$. Strictly decreasing.
• Interval (π, 2π): $\sin x < 0 \implies f'(x) > 0$. Strictly increasing.
• Full Interval (0, 2π): It falls then rises ⟹ neither increasing nor decreasing!

Example 13: f(x) = sin x + cos x on [0, 2π]

f'(x) = cos x - sin x = 0 ⟹ tan x = 1 ⟹ x = π/4, 5π/4

[0, π/4] f'(x) > 0 ⟹ Increasing
(π/4, 5π/4) f'(x) < 0 ⟹ Decreasing
[5π/4, 2π] f'(x) > 0 ⟹ Increasing

Exercise 6.2 Q5: f(x) = 2x³ - 3x² - 36x + 7

f'(x) = 6x² - 6x - 36 = 6(x - 3)(x + 2)
Roots: x = -2 and x = 3 divide ℝ into 3 intervals:
(-∞, -2): 6(-)(-) > 0 ⟹ Strictly Increasing
(-2, 3): 6(-)(+) < 0 ⟹ Strictly Decreasing
(3, ∞): 6(+)(+) > 0 ⟹ Strictly Increasing

Exercise 6.2 Q7: y = log(1+x) - 2x/(2+x)

\frac{dy}{dx} = \frac{1}{1+x} - \frac{(2+x)·2 - 2x(1)}{(2+x)^2} = \frac{1}{1+x} - \frac{4}{(2+x)^2}
\frac{dy}{dx} = \frac{(2+x)^2 - 4(1+x)}{(1+x)(2+x)^2} = \frac{x^2}{(1+x)(2+x)^2}
For x > -1: x² ≥ 0, 1+x > 0, (2+x)² > 0 ⟹ dy/dx ≥ 0!
Hence, y is an increasing function throughout its domain x > -1. Q.E.D.!

§ 6.4 Foundations Hills, Valleys & Critical Points

Maxima and Minima: Local vs Global Extrema

At turning points, a curve transitions from increasing to decreasing (a hill / maximum) or from decreasing to increasing (a valley / minimum).

Definition 4 & Theorem 2 (Fermat's Theorem)

• Local Maximum: $f(c) \ge f(x)$ for all $x \in (c-h, c+h)$.
• Local Minimum: $f(c) \le f(x)$ for all $x \in (c-h, c+h)$.
• Theorem 2: If $f$ has a local extremum at $x = c$, then either $f'(c) = 0$ or $f$ is not differentiable at $c$.

Critical Point Definition: Any point c in domain where f'(c) = 0 or f'(c) does not exist.

⚠️ Converse Fails: Point of Inflection

Just because $f'(c) = 0$ does NOT mean $c$ is an extremum! Consider $f(x) = x^3$:

• f'(x) = 3x² ⟹ f'(0) = 0
• For x < 0: f(x) < 0 (below axis)
• For x > 0: f(x) > 0 (above axis)
⟹ x = 0 is a Point of Inflection, neither max nor min!
Section 6.4 • First Derivative Test Part - 1

6.4 Theorem 3: The First Derivative Test for Local Extrema

Part - 1

Sign Flip (+ to - ⟹ Maxima, - to + ⟹ Minima), Points of Inflection (x³ at origin)

§ 6.4 Theorem 3 First Derivative Test for Local Extrema

The First Derivative Test: Sign Flip Rules

Let $f$ be continuous at a critical point $c$. We inspect how the sign of $f'(x)$ changes as $x$ increases through $c$ from left to right.

Sign Flip: + to -
f'(x) > 0 (left)
f'(x) < 0 (right)

⟹ Local Maximum at c

Sign Flip: - to +
f'(x) < 0 (left)
f'(x) > 0 (right)

⟹ Local Minimum at c

No Sign Change
f'(x) keeps same sign on both sides

⟹ Point of Inflection

Example 17 Walkthrough: f(x) = x³ - 3x + 3

f'(x) = 3x² - 3 = 3(x - 1)(x + 1) = 0 ⟹ Critical points: x = -1 and x = 1.
• At x = -1: Left (-1.1) f' > 0, Right (-0.9) f' < 0. Sign flips + to - ⟹ Local Maxima at x = -1, max value = f(-1) = 5.
• At x = 1: Left (0.9) f' < 0, Right (1.1) f' > 0. Sign flips - to + ⟹ Local Minima at x = 1, min value = f(1) = 1.
Section 6.4 • Second Derivative Test Part - 1

6.4 Theorem 4: The Second Derivative Test & Corner Cases

Part - 1

f'(c) = 0 with f''(c) < 0 (Maxima), f''(c) > 0 (Minima), Test Failure & Non-Differentiable Peaks (3 + |x|)

§ 6.4 Theorem 4 Concavity & Curvature Test

The Second Derivative Test: Concavity at Critical Points

When $f$ is twice differentiable at a critical point $c$ where $f'(c) = 0$, evaluating $f''(c)$ reveals concavity in a single calculation!

Second Derivative Rules

f'(c) = 0  and  f''(c) < 0 ⟹ Local Maximum (Concave Down ⌢)
f'(c) = 0  and  f''(c) > 0 ⟹ Local Minimum (Concave Up ⌣)
f'(c) = 0  and  f''(c) = 0 ⟹ TEST FAILS! (Use 1st Derivative Test)

Non-Differentiable Extrema: f(x) = 3 + |x|

$f(x) = 3 + |x|$ has a sharp corner at $x = 0$, so $f''(0)$ does not exist (2nd derivative test impossible).

For x < 0: f'(x) = -1 < 0 (Decreasing)
For x > 0: f'(x) = +1 > 0 (Increasing)
By First Derivative Test: x = 0 is a local minimum, value = f(0) = 3!

6.4.1 Absolute Maxima & Minima in a Closed Interval

Part - 1

§ 6.4.1 Global Extrema Extreme Value Theorem on [a, b]

Absolute Maximum & Minimum in Closed Intervals

Theorem 5 guarantees that every continuous function on $[a, b]$ attains an absolute maximum and minimum. The absolute extremum may occur at an interior critical point OR at the boundary endpoints $a$ and $b$!

The 4-Step Working Rule

  1. Step 1: Find all interior critical points in $(a, b)$ where $f'(x) = 0$ or $f'$ is undefined.
  2. Step 2: Note the endpoints $x = a$ and $x = b$.
  3. Step 3: Calculate $f(x)$ at ALL critical points and endpoints.
  4. Step 4: The largest value is the Absolute Maximum; the smallest is the Absolute Minimum.

Example 27: f(x) = 2x³ - 15x² + 36x + 1 on [1, 5]

f'(x) = 6(x - 2)(x - 3) = 0 ⟹ Critical points: x = 2, 3.
Evaluate all 4 candidate points:
• f(1) = 24    [Endpoint 1]
• f(2) = 29    [Critical Point]
• f(3) = 28    [Critical Point]
• f(5) = 56    [Endpoint 5]
Absolute Maximum = 56 (at x = 5); Absolute Minimum = 24 (at x = 1)!

6.4 Applied Optimization 1: Geometry & Trajectories

Part - 1

Applied Optimization 1 Geometry & Shortest Distances

Distance Minimization & Trajectory Interceptions

When minimizing distances $D = \sqrt{(x - x_0)^2 + (y - y_0)^2}$, minimize $D^2$ instead! This eliminates bulky square roots while keeping the extremum location identical.

Example 29: Apache Helicopter on y = x² + 7

Soldier placed at $(3, 7)$. Find nearest distance:

D² = (x - 3)² + (x² + 7 - 7)² = (x - 3)² + x⁴
d(D²)/dx = 2(x - 3) + 4x³ = 4x³ + 2x - 6 = 2(x - 1)(2x² + 2x + 3) = 0
Root: x = 1 (quadratic factor has Δ < 0)
Minimum D = √[(1 - 3)² + 1⁴] = √(4 + 1) = √5
Nearest distance is exactly √5!

Example 24: Two Vertical Poles Wire Tie

Poles $AP = 16\text{ m}$, $BQ = 22\text{ m}$, distance $AB = 20\text{ m}$. Find point $R$ on $AB$ minimizing $RP^2 + RQ^2$:

Let AR = x, RB = 20 - x
S(x) = (x² + 16²) + ((20 - x)² + 22²) = 2x² - 40x + 1140
S'(x) = 4x - 40 = 0 ⟹ x = 10 m
S''(x) = 4 > 0 (Minimum confirmed)
Tie wire at AR = 10 m (exact midpoint!).

Industrial optimization problems balance material constraints against volume and area. We prove that optimal shapes possess highly symmetric dimensional ratios!

Example 25: Trapezium with 3 Sides Equal to 10 cm

Area A(x) = (x + 10)√(100 - x²)
A'(x) = \frac{-2x² - 10x + 100}{\sqrt{100 - x²}} = 0
2x² + 10x - 100 = 0 ⟹ x = 5 cm (distance > 0)
Max Area = (5 + 10)√(100 - 25) = 15√75 = 75√3 cm²!

Example 26: Cylinder Inscribed in Cone

Cone has radius $r$ and height $h$. Find cylinder radius $x$ for maximum curved surface area:

Height of cylinder: QE = \frac{h(r - x)}{r}
Curved Surface Area S(x) = 2\pi x · \frac{h(r - x)}{r} = \frac{2\pi h}{r}(rx - x²)
S'(x) = \frac{2\pi h}{r}(r - 2x) = 0 ⟹ x = r / 2
Cylinder radius is exactly half the cone radius!

Exercise 6.3 Q23: Largest Cone in Sphere

Prove maximum cone volume is $\frac{8}{27}$ of sphere volume:

Let cone height h = R + x ⟹ r_c² = R² - x²
V(x) = \frac{1}{3}\pi (R² - x²)(R + x)
V'(x) = \frac{1}{3}\pi (R - 3x)(R + x) = 0 ⟹ x = R/3
h = R + R/3 = 4R/3,   r_c² = 8R²/9
V_cone = \frac{1}{3}\pi (\frac{8R²}{9})(\frac{4R}{3}) = \frac{32\pi R³}{81}
V_cone = \frac{8}{27} · [\frac{4}{3}\pi R³] = \frac{8}{27} V_sphere  [Q.E.D.!]

Exercise 6.3 Q25: Optimal Semi-Vertical Angle

Given slant height $l$, maximize volume $V$:

r = l sin α,   h = l cos α
V(α) = \frac{1}{3}\pi l³ \sin²α \cos α
dV/dα = \frac{1}{3}\pi l³ [2\sin α \cos²α - \sin³α] = 0
2\cos²α = \sin²α ⟹ \tan²α = 2 ⟹ \tan α = \sqrt{2}
Semi-vertical angle α = tan⁻¹(√2)! [Q.E.D.]

Determinants: The Scalar Metric of Square Matrices

"All Mathematical truths are relative and conditional." — C.P. Steinmetz

📐 Genesis: Solving 2 Linear Equations

Consider a classical system of two linear algebraic equations in two variables:

a₁x + b₁y = c₁
a₂x + b₂y = c₂
⟺
a₁   b₁
a₂   b₂ x
y = c₁
c₂
The Uniqueness Condition:

Recall from coordinate geometry: this system has a unique solution if and only if:

a₁ / a₂ ≠ b₁ / b₂   ⟺   a₁b₂ – a₂b₁ ≠ 0

The single scalar number a₁b₂ – a₂b₁ determines whether a unique solution exists or not. This crucial scalar is defined as the determinant of matrix A, denoted by |A| or det A or Δ.

Definition 4.2

Determinant as a Mathematical Function

If M is the set of all square matrices and K is the field of scalars, then a determinant is a mapping:

f: M → K,   where f(A) = k ∈ K
⚠️ Two Golden Remarks:
1. For matrix A, |A| is read as "determinant of A", NOT modulus of A!
2. Only SQUARE matrices have determinants.
🏛️

§ 4.2.1 & § 4.2.2 • Order 1 & Order 2 NCERT Pages 77–78

Determinants of Order 1 & Order 2 × 2

From single-scalar entries to the cross-multiplication algorithm of second-order determinants.

Order 1 Determinant

If A = [a] is a 1 × 1 matrix, then:

|A| = |[a]| = a
Example: If A = [–5], |A| = –5 (NOT +5!).
Order 2 × 2 Determinant Formula

Let A = [ [a₁₁, a₁₂], [a₂₁, a₂₂] ]. The determinant is:

|A| = Δ = a₁₁a₂₂ – a₂₁a₁₂

Multiply the principal diagonal elements, then subtract the off-diagonal product.

Example 1:
| [2, 4], [–1, 2] |
= 2(2) – 4(–1)
= 4 + 4 = 8
Example 2:
| [x, x+1], [x–1, x] |
= x² – (x+1)(x–1)
= x² – (x²–1) = 1

§ 4.2.3 • Order 3 × 3 Master Algorithm NCERT Pages 78–79

Expansion of 3 × 3 Determinant along First Row (R₁)

The canonical 4-step expansion expressing third-order determinants as linear combinations of 2 × 2 minors.

Step 1 (–1)¹⁺¹ = +1
Element a₁₁ (Row 1, Col 1)

Delete R₁ and C₁. Multiply a₁₁ by remaining 2 × 2 sub-determinant:

+ a₁₁ (a₂₂a₃₃ – a₃₂a₂₃)
Step 2 (–1)¹⁺² = –1
Element a₁₂ (Row 1, Col 2)

Delete R₁ and C₂. Multiply a₁₂ by –1 and the sub-determinant:

– a₁₂ (a₂₁a₃₃ – a₃₁a₂₃)
Step 3 (–1)¹⁺³ = +1
Element a₁₃ (Row 1, Col 3)

Delete R₁ and C₃. Multiply a₁₃ by +1 and the sub-determinant:

+ a₁₃ (a₂₁a₃₂ – a₃₁a₂₂)
Step 4 Sum All 3
Complete Master Expression

Sum all 3 signed products together:

|A| = Term₁ + Term₂ + Term₃
Checkerboard Signs of (–1)ⁱ⁺ʲ
+ – + – + – + – +

Alternating signs: Positive if (i + j) is even, Negative if (i + j) is odd.

Full Algebraic 6-Term Expansion (Equation 1):
|A| = a₁₁ a₂₂ a₃₃ – a₁₁ a₃₂ a₂₃ – a₁₂ a₂₁ a₃₃ + a₁₂ a₃₁ a₂₃ + a₁₃ a₂₁ a₃₂ – a₁₃ a₃₁ a₂₂
Notice: 3 terms with positive signs and 3 terms with negative signs, each containing exactly one element from each row and each column!
§ 4.2.3 • Expansion Invariance & Scaling NCERT Pages 79–81

Row/Column Invariance & The Scaling Law |kA| = kⁿ|A|

Expanding along any row or column yields the exact same determinant value. Always choose rows with maximum zeroes!

NCERT Example 3 Fastest Shortcut

Evaluating Determinant with Maximum Zeroes:

 1   2   4
–1   3   0
 4   1   0
Third Column (C₃) has TWO zeroes!
Expand along C₃:
Δ = 4 | [–1, 3], [4, 1] | – 0 + 0
  = 4( (–1)(1) – (3)(4) )
  = 4(–1 – 12) = 4(–13) = –52

Expanding along C₃ took only 1 calculation instead of 3!

Golden Theorem (§ 4.2.3)

The Scalar Multiplication Determinant Law

If A is an n × n square matrix and k is any scalar:

|kA| = kⁿ |A|
Order n = 2:
A = 2 × 2
|2A| = 2² |A| = 4|A|
Exercise 4.1 Q3
Order n = 3:
A = 3 × 3
|3A| = 3³ |A| = 27|A|
Exercise 4.1 Q4
💡 Why? Because scalar k multiplies into every row! In order n, k factors out n times: k · k · ... · k = kⁿ.

§ 4.4 Minors & Cofactors NCERT Pages 84–85

Minors (Mᵢⱼ) & Cofactors (Aᵢⱼ)

Deconstructing any determinant into its sub-determinants and sign-weighted cofactor components.

Definition 1

Minor of an Element (Mᵢⱼ)

Minor of an element aᵢⱼ is the determinant obtained by deleting its i-th row and j-th column in which element aᵢⱼ lies. Denoted by Mᵢⱼ.

Example 8: Find minor of 6 in | [1, 2, 3], [4, 5, 6], [7, 8, 9] |
6 lies in row 2, col 3. Delete R₂ and C₃:
M₂₃ = | [1, 2], [7, 8] | = 1(8) – 2(7) = 8 – 14 = –6
Order Reduction: Minor of an element of order n is always a determinant of order n – 1.
Definition 2

Cofactor of an Element (Aᵢⱼ)

Cofactor of an element aᵢⱼ, denoted by Aᵢⱼ, is defined by attaching the position sign to its minor:

Aᵢⱼ = (–1)ⁱ⁺ʲ Mᵢⱼ
Example: In | [1, –2], [4, 3] |
M₁₁ = 3 ⇒ A₁₁ = (–1)¹⁺¹(3) = 3
M₁₂ = 4 ⇒ A₁₂ = (–1)¹⁺²(4) = –4
M₂₁ = –2 ⇒ A₂₁ = (–1)²⁺¹(–2) = 2
M₂₂ = 1 ⇒ A₂₂ = (–1)²⁺²(1) = 1

§ 4.4 The Orthogonality Property NCERT Pages 85–86

Cofactor Orthogonality: Own Row vs Other Row

Multiplying elements of a row by their own cofactors yields |A|, but multiplying by another row's cofactors vanishes to zero!

Property 1: Self Product

Elements × Own Row's Cofactors = |A|

The determinant is simply the dot product of any row (or column) with its own cofactors:

R₁:   a₁₁A₁₁ + a₁₂A₁₂ + a₁₃A₁₃ = |A|
C₁:   a₁₁A₁₁ + a₂₁A₂₁ + a₃₁A₃₁ = |A|

Holds equally for all 3 rows and all 3 columns.

Property 2: Cross Product

Elements × OTHER Row's Cofactors = 0!

If elements of a row are multiplied with cofactors of any other row, their sum is identically zero:

R₁ elements with R₂ cofactors:
a₁₁A₂₁ + a₁₂A₂₂ + a₁₃A₂₃ = 0
💡 Proof insight: This linear combination represents expanding a determinant where row 1 and row 2 are identical! Since identical rows mean zero determinant, the sum must be 0!
NCERT Example 11 Numerical Verification:

For A = [ [2, –3, 5], [6, 0, 4], [1, 5, –7] ], verifying a₁₁A₃₁ + a₁₂A₃₂ + a₁₃A₃₃ = 0:

a₁₁ = 2, a₁₂ = –3, a₁₃ = 5   |   A₃₁ = –12, A₃₂ = 22, A₃₃ = 18
Sum = 2(–12) + (–3)(22) + 5(18) = –24 – 66 + 90 = 0 ✓ (Verified!)
§ 4.5 Adjoint of a Matrix NCERT Pages 87–89

Adjoint of a Square Matrix (adj A) & Key Theorems

Definition as the transpose of the cofactor matrix, the 2 × 2 fast shortcut, and fundamental theorems.

Definition 3

adj A = Transpose of [Aᵢⱼ]

The adjoint of a square matrix A is defined as the transpose of its cofactor matrix:

adj A = [ [A₁₁, A₂₁, A₃₁], [A₁₂, A₂₂, A₃₂], [A₁₃, A₂₃, A₃₃] ]
⚡ 2 × 2 Instant Shortcut:

To find adj of A = [ [a, b], [c, d] ]:

adj A = [ [d, –b], [–c, a] ]

Swap diagonal entries (a ↔ d), negate off-diagonal entries (–b, –c)!

Master Theorem 1

A · (adj A) = (adj A) · A = |A| I

Multiplying A by its adjoint produces a scalar diagonal matrix with |A| on the diagonal:

A (adj A) = [ [|A|, 0, 0], [0, |A|, 0], [0, 0, |A|] ] = |A| I
Determinant of Adjoint Theorem:
|(adj A)| · |A| = |A|³  ⇒  |adj A| = |A|ⁿ⁻¹
For order 3: |adj A| = |A|² (Exercise 4.4 Q17).
Singular vs Non-singular: A matrix is singular if |A| = 0; non-singular if |A| ≠ 0.

§ 4.5.1 Invertibility NCERT Pages 90–93

Inverse of a Matrix (A⁻¹) & Matrix Equations

Invertibility condition, the adjoint formula, reversal law, and finding A⁻¹ from characteristic polynomials.

Theorem 4

A is Invertible ⟺ A is Non-singular (|A| ≠ 0)

If |A| ≠ 0, the unique inverse matrix A⁻¹ is given by:

A⁻¹ = (1 / |A|) · adj A
Reversal Law: (AB)⁻¹ = B⁻¹ A⁻¹ (Example 14)
Determinant of Inverse: det(A⁻¹) = 1 / det(A)
Double Inverse: (A⁻¹)⁻¹ = A
NCERT Example 15

Inversion via Matrix Equation A² – 4A + I = O

Do not compute adj A manually when a polynomial relationship is provided:

1. A² – 4A + I = O
2. Multiply both sides by A⁻¹:
A·(AA⁻¹) – 4(AA⁻¹) + IA⁻¹ = O
A·I – 4I + A⁻¹ = O
3. Solve directly for A⁻¹:
A⁻¹ = 4I – A
For A = [ [2, 3], [1, 2] ], A⁻¹ = 4I – A = [ [4–2, –3], [–1, 4–2] ] = [ [2, –3], [–1, 2] ].

Solving AX = B & Consistency Testing

Case I: |A| ≠ 0 (Nonsingular Matrix)

Unique solution exists: X = A⁻¹ B. System is consistent.

• If (adj A) · B ≠ O ⇒ Inconsistent (No solution) (Ex 4.5 Q3)
• If (adj A) · B = O ⇒ Consistent (infinitely many) OR Inconsistent

Section 4.1 • Introduction

What is a Quadratic Equation?

When a quadratic polynomial p(x) = ax² + bx + c (a ≠ 0) is equated to zero, we get a quadratic equation: ax² + bx + c = 0.

🏛️
NCERT Fig. 4.1
Prayer Hall: Area = 300 m²

📐 The Prayer Hall Problem (NCERT Page 38)

A charity trust builds a hall of area 300 m². The length is one metre more than twice its breadth.

Let breadth = x metres
Then length = (2x + 1) metres
Area = Length × Breadth = (2x + 1)x = 2x² + x
2x² + x = 300 ⟹ 2x² + x - 300 = 0

📜 Centuries of Mathematical Discovery

Babylonians & Euclid: Solved geometric problems equivalent to x² - px + q = 0.
Brahmagupta (C.E. 598–665): Ancient Indian mathematician who gave explicit formula for ax² + bx = c.
Sridharacharya (C.E. 1025): Derived the famous Quadratic Formula using completing the square (quoted by Bhaskara II).
NCERT Section 4.2 • Example 2

Standard Form & Disguised Equations

Standard form is ax² + bx + c = 0 (a ≠ 0). Warning: You must always simplify first before deciding whether an equation is quadratic!

Trap 1 • Appears Quadratic
x(x + 1) + 8 = (x + 2)(x - 2)
LHS = x² + x + 8
RHS = x² - 4
x² cancels out! ⟹ x + 12 = 0
❌ NOT quadratic (Degree is 1, linear).
Trap 2 • Appears Cubic
(x + 2)³ = x³ - 4
LHS = x³ + 6x² + 12x + 8
RHS = x³ - 4
x³ cancels out! ⟹ 6x² + 12x + 12 = 0 (x² + 2x + 2 = 0)
✅ IS a quadratic equation!

NCERT Section 4.3 • Factorisation

Solving by Factorisation (Splitting Middle Term)

A real number α is a root of ax² + bx + c = 0 if aα^2 + bα + c = 0. The roots of the equation and the zeroes of the polynomial are identical!

NCERT Section 4.4 • The Universal Formula

Sridharacharya's Quadratic Formula

Works on every quadratic equation, even when middle term splitting is difficult or impossible!

The Golden Formula
x = -b ± √(b² - 4ac) / 2a

provided the term under the square root b² - 4ac ≥ 0.

-b
Opposite of middle coefficient
b² - 4ac
The Discriminant (D)
2a
Twice the leading coefficient
NCERT Section 4.4 • Discriminant (D = b² - 4ac)

Nature of Roots: The 3 Discriminant Cases

The quantity D = b² - 4ac discriminates the nature of roots before solving!

Case 1

b² - 4ac > 0

Positive discriminant yields two real values from ± √(D).

Two Distinct Real Roots
(-b + √D)/2a & (-b - √D)/2a
Case 2

b² - 4ac = 0

Zero discriminant collapses ± √(0) = 0.

Two Equal Real Roots (Coincident)
-b / 2a & -b / 2a
Case 3

b² - 4ac < 0

Negative under square root has no real number solution.

No Real Roots
(Parabola does not cut x-axis)

NCERT Pages 45-46 • Example 8

Geometric Modeling: Pole on Circular Boundary

A pole P is erected on the boundary of a circular park of diameter 13 m such that the difference of distances from opposite gates A and B is 7 m.

Angle APB = 90° (Angle in a semicircle)

Pythagorean Theorem Formulation

AP² + PB² = AB²
(x + 7)² + x² = 13² = 169
x² + 14x + 49 + x² = 169 ⟹ 2x² + 14x - 120 = 0
⟹ x² + 7x - 60 = 0
Discriminant: D = 7² - 4(1)(-60) = 49 + 240 = 289 > 0 (Real roots!)
x = (-7 ± √289) / 2 = (-7 ± 17) / 2
x = 5 m (Distance from Gate B)
x + 7 = 12 m (Distance from Gate A)
NCERT Page 47 • High Frequency Exam Question

Finding 'k' When Equation Has Equal Roots

When a quadratic equation has two equal real roots, the discriminant must be exactly zero: b² - 4ac = 0.

Problem (i): 2x² + kx + 3 = 0

Here a = 2, b = k, c = 3
For equal roots: D = b² - 4ac = 0
k² - 4(2)(3) = 0
k² - 24 = 0 ⟹ k² = 24
k = ±√24 = ±2√6

Problem (ii): kx(x - 2) + 6 = 0

Expand: kx² - 2kx + 6 = 0
Here a = k, b = -2k, c = 6
D = (-2k)² - 4(k)(6) = 0
4k² - 24k = 0 ⟹ 4k(k - 6) = 0
Since k ≠ 0 (otherwise degree 2 is lost):
k = 6

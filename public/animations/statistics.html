The Science of Central Tendency

In everyday life, raw data is massive and chaotic. Statistics condenses thousands of observations into single representative numbers that capture the essence of the entire distribution.

Method 1 • Direct

The Direct Method

Direct Mean Formula
x̄ = (Σ fᵢ xᵢ) / (Σ fᵢ)

Since class intervals like 10-25 contain continuous spread, we assume that the frequency is centered at the Class Mark (xᵢ):

xᵢ = (Upper Limit + Lower Limit) / 2
NCERT Critical Observation (Page 174)

For the 30-student marks data:
• Exact ungrouped mean = 59.3
• Grouped direct mean = 62.0
Why the difference? Because grouping assumes all observations inside each interval are equal to its midpoint xᵢ!

Method 2 • Deviation

Assumed Mean Method

When numerical values of xᵢ and fᵢ become large, calculating fᵢ xᵢ is tedious. We subtract a constant assumed center a from each xᵢ:

Deviation Formula
dᵢ = xᵢ - a
Formal Proof:
d̄ = (Σ fᵢ dᵢ) / (Σ fᵢ) = (Σ fᵢ(xᵢ - a) / (Σ fᵢ)
d̄ = (Σ fᵢ xᵢ) / (Σ fᵢ) - (a Σ fᵢ) / (Σ fᵢ) = x̄ - a
→ x̄ = a + (Σ fᵢ dᵢ) / (Σ fᵢ)

Activity 1 Note: No matter which xᵢ you choose as a, the final mean will always equal 62!

Method 3 • Scaling

Step-Deviation Method

Notice in Table 13.4 that all deviations dᵢ ∈ \{-30, -15, 0, 15, 30, 45\} share a common factor h = 15 (the class size). Dividing by h reduces calculations to tiny single-digit integers:

Step-Deviation Form
uᵢ = (xᵢ - a) / (h)
Derivation (Page 177):
ū = (Σ fᵢ uᵢ) / (Σ fᵢ) = (1) / (h)≤ft[(Σ fᵢ xᵢ - a Σ fᵢ) / (Σ fᵢ)] = (x̄ - a) / (h)
h ū = x̄ - a
→ x̄ = a + h ≤ft(Σ fᵢ uᵢ) / (Σ fᵢ)
When to Use Which Method?
  • Direct: When xᵢ and fᵢ are small numbers (e.g. single digits).
  • Assumed Mean: When numbers are large but no common factor exists.
  • Step-Deviation: When all dᵢ share a convenient common divisor h.

Solving Missing Frequency f

Daily pocket allowance of children: 11-13 (7), 13-15 (6), 15-17 (9), 17-19 (13), 19-21 (f), 21-23 (5), 23-25 (4). Find f.

1. Total Children: Σ fᵢ = 44 + f
2. Class marks: xᵢ ∈ \{12, 14, 16, 18, 20, 22, 24\}
3. Setting a = 18 → dᵢ ∈ \{-6, -4, -2, 0, 2, 4, 6\}
4. Σ fᵢ dᵢ = (-42 - 24 - 18) + 0 + 2f + 20 + 24 = 2f - 40
5. Since x̄ = a → d̄ = 0:
(2f - 40) / (44 + f) = 0 → 2f - 40 = 0 → f = 20
Answer Verified: Missing Frequency f = 20 children
Section 13.3 • The Most Popular Value

Mode of Grouped Data

In grouped distributions, we cannot pick the mode simply by looking. We first locate the Modal Class (class with maximum frequency f₁), and then interpolate inside it:

NCERT Grouped Mode Formula
Mode = l + ≤ft(f₁ - f₀) / (2f₁ - f₀ - f₂) × h
l: Lower limit of modal class
h: Class size interval
f₁: Frequency of modal class
f₀: Preceding frequency
How does the formula work?

The modal class is the tallest bar in a histogram. The adjacent bars (f₀ on the left and f₂ on the right) pull the true peak toward whichever neighbor has a higher frequency!

Example 5: 20 Household Family Sizes

Max Frequency = 8
Family Size 1 - 3 3 - 5 (Modal) 5 - 7 7 - 9 9 - 11
Families f₀ = 7 f₁ = 8 f₂ = 2 2 1
Modal Class = 3 - 5 → l = 3, h = 2, f₁ = 8, f₀ = 7, f₂ = 2
Mode = 3 + ≤ft(8 - 7) / (2(8) - 7 - 2) × 2 = 3 + ≤ft(1) / (16 - 9) × 2 = 3 + (2) / (7) ≈ 3.286

Section 13.4 Foundations

Cumulative Frequency (cf)

Cumulative frequency is the running total of frequencies up to a specified boundary. There are two complementary perspectives:

1. "Less Than" Type (Uses Upper Limits) Accumulates from left to right: How many students scored less than 10, 20, 30...?
2. "More Than or Equal To" Type (Uses Lower Limits) Starts with total n and subtracts: How many students scored ≥ 0, ≥ 10, ≥ 20...?
The Ogive Intersection Property

If you plot both the "Less than ogive" and "More than ogive" on the same graph, their point of intersection on the x-axis gives the exact Median!

Section 13.4 • Grouped Median

Median of Grouped Data

NCERT Grouped Median Formula
Median = l + ≤ft(n) / (2) - cf) / (f) × h
Step 1: Find total n = Σ fᵢ and calculate (n) / (2).
Step 2: Locate the Median Class (cf ≥ (n) / (2).
CRITICAL TRAP: cf in the formula is the cumulative frequency of the class preceding the median class, while f is the frequency of the median class itself!

Example 8 • High-Yield Exam Master

Finding Two Unknowns (x & y)

Given that the Median = 525 and total frequency n = 100, find the values of missing frequencies x and y.

Equation (1) from Total Count:
Sum of frequencies = 76 + x + y = 100
→ x + y = 24
Discontinuous Classes Rule (Ex 13.3 Q4)

If class intervals are discontinuous (e.g. 118-126, 127-135), you MUST subtract 0.5 from lower limit and add 0.5 to upper limit to make them continuous (117.5-126.5, 126.5-135.5) before applying Median or Mode formulas!

The Reverse Median Deduction

525 falls in [500 – 600]
1. Locate Median Class from the Median value itself:
Since Median = 525, the median class is 500 – 600!
l = 500, h = 100, f = 20, cf = 36 + x (class preceding)
2. Substitute into Median Formula:
525 = 500 + ≤ft[(50 - (36 + x) / (20)] × 100
525 - 500 = (14 - x) × 5
25 = 70 - 5x → 5x = 45 → x = 9
3. Solve for y using Equation (1):
9 + y = 24 → y = 15
Solution Confirmed:
x = 9 • y = 15
The Golden Formula • Page 197

Empirical Relationship

For moderately skewed frequency distributions, there is a constant connection between the three measures discovered by Karl Pearson:

Empirical Formula
3 Median = Mode + 2 Mean
or Mode = 3 Median - 2 Mean
When to use Mean: When all observations carry equal weight and distribution is uniform (e.g. school marks).
When to use Median: When extreme outliers exist (e.g. country wages, house prices, worker productivity).
When to use Mode: When determining the most popular consumer choice (e.g. popular shoe size, TV show ratings).

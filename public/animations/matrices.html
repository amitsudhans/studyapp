§ 3.1 & 3.2 Matrix Foundations

What is a Matrix? Real-World Representation

A matrix is an ordered rectangular array of numbers or functions. The evolution of matrices originated as a compact method for solving systems of linear equations. Today, their utility extends to electronic spreadsheets, computer graphics (rotation, reflection, magnification), cryptography, genetics, economics, and quantum mechanics!

§ 3.2.1 Matrix Dimensions & Indexing

Order of a Matrix (m × n) & Element Indexing

A matrix with m rows and n columns has order m × n (read "m by n"). The entry lying in the i-th row and j-th column is denoted by aᵢⱼ. The total number of elements is equal to the product mn.

General Array Notation:
a₁₁   a₁₂   ...   a₁ₙ
a₂₁   a₂₂   ...   a₂ₙ
 :     :     :     :
aₘ₁   aₘ₂   ...   aₘₙ

Where 1 ≤ i ≤ m, 1 ≤ j ≤ n, with i, j ∈ ℕ.

§ 3.3.1 Definition 2 & Examples 4, 5

Equality of Matrices & Solving Unknowns

Two matrices A = [aᵢⱼ] and B = [bᵢⱼ] are equal (A = B) if and only if:
1. They have the exact same order.
2. Every corresponding entry is equal: aᵢⱼ = bᵢⱼ for all i and j.

Example 4: 6-Variable Matrix Equality
[ x+3   z+4   2y-7 ]   =   [  0    6   3y-2 ]
[ -6    a-1     0    ]   =   [ -6   -3   2c+2 ]
[ b-3   -21     0    ]   =   [ 2b+4  -21   0   ]
• x + 3 = 0 ⇒ x = -3
• z + 4 = 6 ⇒ z = 2
• 2y - 7 = 3y - 2 ⇒ y = -5
• a - 1 = -3 ⇒ a = -2
• 0 = 2c + 2 ⇒ c = -1
• b - 3 = 2b + 4 ⇒ b = -7
Example 5: Linear System via Equality
[ 2a + b   a - 2b ]   =   [  4   -3 ]
[ 5c - d   4c + 3d ]   =   [ 11   24 ]
Solve (a, b): 2a + b = 4 and a – 2b = –3
Multiplying: 4a + 2b = 8 ⇒ 5a = 5 ⇒ a = 1, b = 2.
Solve (c, d): 5c – d = 11 and 4c + 3d = 24
15c – 3d = 33 ⇒ 19c = 57 ⇒ c = 3, d = 4.
§ 3.4.1 - 3.4.4 Operations

Matrix Addition, Scalar Scaling & Their Laws

Addition requires identical dimensions: cᵢⱼ = aᵢⱼ + bᵢⱼ. Scalar multiplication scales every entry by k: kA = [k aᵢⱼ]. Difference is defined as A – B = A + (–1)B.

Laws of Matrix Addition:
1. Commutative Law: A + B = B + A
2. Associative Law: (A + B) + C = A + (B + C)
3. Additive Identity: A + O = O + A = A
4. Additive Inverse: A + (–A) = O
Scalar Scaling & Linear Equation:
k(A + B) = kA + kB
(k + l)A = kA + lA
Example 8 Solving: 2A + 3X = 5B
Subtract 2A: 3X = 5B – 2A ⇒ X = ⅓(5B – 2A).
§ 3.4.5 The Dot Product of Rows & Columns

Matrix Multiplication: Compatibility & Mechanics

The product AB is defined IF AND ONLY IF the number of columns in A equals the number of rows in B!
If A has order m × n and B has order n × p, the product C = AB has order m × p.

The (i, k)-th Element Formula:
cᵢₖ = aᵢ₁b₁ₖ + aᵢ₂b₂ₖ + ... + aᵢₙbₙₖ
cᵢₖ = ∑ⱼ₌₁ⁿ aᵢⱼ · bⱼₖ

We take the i-th row of A and multiply element-wise with the k-th column of B, then sum all products together.

§ 3.4.5 & 3.4.6 Essential Properties

Non-Commutativity & Zero Divisors

Matrix multiplication differs drastically from ordinary real numbers: AB ≠ BA in general, and AB = O does NOT mean A = O or B = O!

1. AB ≠ BA in General:

Example 14:
A = [1 0; 0 -1], B = [0 1; 1 0]
⇒ AB = [0 1; -1 0]
⇒ BA = [0 -1; 1 0]
Clearly AB ≠ BA!

Exception: Diagonal matrices of the same order always commute!
2. Zero Divisors (Ex 15):

In real algebra, ab = 0 implies a = 0 or b = 0. In matrices:

A = [ 0 -1; 0 2 ] ≠ O
B = [ 3  5; 0 0 ] ≠ O
AB = [ 0 0; 0 0 ] = O!
3. Valid Algebraic Laws:
Associative: (AB)C = A(BC)
Distributive: A(B+C) = AB + AC
Multiplicative Identity: IA = AI = A
§ 3.5 Transpose & Properties

Transpose of a Matrix (A′ or Aᵀ) & Reversal Law

The transpose is obtained by interchanging rows and columns: if A = [aᵢⱼ]ₘₓₙ, then A′ = [aⱼᵢ]ₙₓₘ.

4 Fundamental Properties:
(i) Double Transpose: (A′)′ = A
(ii) Scalar Scaling: (kA)′ = kA′
(iii) Addition Rule: (A + B)′ = A′ + B′
(iv) Reversal Law: (AB)′ = B′A′
Why Does Order Reverse in (AB)′ = B′A′?

If A is m × n and B is n × p, then AB is m × p, and its transpose (AB)′ has order p × m.

To obtain order p × m from the transposes, we MUST multiply B′ (order p × n) with A′ (order n × m):

B′₍ₚ ₓ ₙ₎ × A′₍ₙ ₓ ₘ₎ = (B′A′)₍ₚ ₓ ₘ₎ = (AB)′!
§ 3.6 Theorems 1 & 2

Symmetric & Skew-Symmetric Decomposition

A square matrix is Symmetric if A′ = A. It is Skew-Symmetric if A′ = –A.

Critical Property: Diagonal Elements of Skew Matrix

If A is skew-symmetric, then aⱼᵢ = –aᵢⱼ.
For diagonal entries, set i = j:

aᵢᵢ = –aᵢᵢ  ⇒  2aᵢᵢ = 0  ⇒  aᵢᵢ = 0 for all i!
Theorem 1: For any square matrix A, A + A′ is symmetric, and A – A′ is skew-symmetric.
Theorem 2: Unique Decomposition

Any square matrix A can be uniquely expressed as the sum of a symmetric and a skew-symmetric matrix:

A = ½(A + A′) + ½(A – A′)
A = P (Symmetric) + Q (Skew-Symmetric)

This powerful result guarantees that any square grid of numbers splits cleanly into mirror-reflection and anti-symmetric components.

§ 3.7 Invertibility & Theorems 3, 4

Invertible Matrices & Uniqueness of Inverses

If A is a square matrix of order m, and there exists another square matrix B such that AB = BA = I, then B is called the inverse of A (B = A⁻¹).

Square Requirement:

A rectangular matrix never possesses an inverse, because for AB and BA to both equal I, both matrices must be square and of identical order.

Theorem 3: Uniqueness of Inverse

The inverse of a square matrix, if it exists, is unique.

Proof: If AB = I and AC = I, then B = BI = B(AC) = (BA)C = IC = C!
Theorem 4: Reversal Law of Inverses

If A and B are invertible matrices of the same order:

(AB)⁻¹ = B⁻¹A⁻¹

Section 5.1 & 5.2 • Introduction

Patterns in Nature & What is an AP?

Sunflower petals, honeycomb cells, and pine cone spirals all exhibit mathematical patterns. An Arithmetic Progression (AP) is a list of numbers where each term is obtained by adding a fixed number to the preceding term.

🌻
General Form of AP
a, a + d, a + 2d, a + 3d, ...
Salary (₹) d = +500

Reena's Annual Salary

Starts at ₹8000 with ₹500 annual increments.

8000, 8500, 9000, 9500, ...
Ladder (cm) d = -2

Rungs of a Ladder (Fig 5.1)

Bottom rung is 45 cm, decreasing uniformly by 2 cm.

45, 43, 41, 39, 37, 35, ...
Savings (₹) d = +50

Shakila's Daughter Piggy Bank

₹100 on 1st birthday, increased by ₹50 every year.

100, 150, 200, 250, ...
💡 Finite AP has a last term l (e.g. 8 rungs of ladder). Infinite AP continues indefinitely without a last term.
NCERT Page 51 • Critical Theorem

The Common Difference: Positive, Negative, or Zero!

The fixed number d = aₖ₊₁ - aₖ can be positive, negative, or zero. Always subtract the preceding term from the succeeding term!

d > 0 (Increasing)
1, 2, 3, 4, ...
d = 2 - 1 = +1
d < 0 (Decreasing)
100, 70, 40, 10, ...
d = 70 - 100 = -30
d = 0 (Constant)
3, 3, 3, 3, ...
d = 3 - 3 = 0
Radicals (Trap!)
√2, √8, √18, √32
= √2, 2√2, 3√2, 4√2 ⟹ d = √2

Exercise 5.1 Verification Test: Is it an AP?

2, 4, 8, 16, ...

4 - 2 = 2, but 8 - 4 = 4. Since differences are not constant, NOT an AP.

3, 3+√2, 3+2√2, 3+3√2, ...

Every step adds exactly √2. Therefore, IS an AP with d = √2.

Section 5.3 • The General Term

The n-th Term Formula: aₙ = a + (n - 1)d

By observing how each term adds d one fewer time than its position, we deduce the universal formula for the n-th term.

Formula for General Term
aₙ = a + (n - 1)d

where a = first term, d = common difference, and n = position/term number.

Example 3
10th term of 2, 7, 12, ...
a = 2, d = 5, n = 10
a₁₀ = 2 + 9(5) = 47
Example 4
Which term of 21, 18, 15 is -81?
-81 = 21 + (n - 1)(-3)
⟹ n = 35th term!
Divisibility by 3 (Ex 7)
Two-digit numbers: 12, 15, ..., 99
99 = 12 + (n - 1)3
⟹ n = 30 numbers!
NCERT Page 59-60 • Example 8

Finding the n-th Term from the End

Finding terms counted from the last term back towards the first term: Two elegant mathematical techniques!

Method 1: Find Total Terms First

Find the 11th term from the last of AP: 10, 7, 4, ..., -62.

Last term l = -62 = 10 + (n - 1)(-3)
-72 = (n - 1)(-3) ⟹ n - 1 = 24 ⟹ Total n = 25 terms
11th from end = (25 - 11 + 1)th = 15th term from start!
a₁₅ = 10 + 14(-3) = 10 - 42 = -32

Method 2: Reverse the AP (Fastest!)

Flip the AP so the last term becomes the new first term!

New First Term: a' = -62
New Difference: d' = -(-3) = +3
Now simply find the 11th term of this reversed AP:
a'₁₁ = -62 + (11 - 1)(3) = -62 + 30 = -32
Section 5.4 • Sum of n Terms

10-Year-Old Gauss's Genius Trick

Carl Friedrich Gauss instantly summed 1 to 100 by pairing numbers from opposite ends: (1 + 100) = (2 + 99) = … = 101.

Gauss Pairing Technique: Sum = 100 × 101 / 2 = 5050
S = 1 + 2 + 3 + ... + 99 + 100
S = 100 + 99 + 98 + ... + 2 + 1
2S = 101 + 101 + 101 + ... + 101 (100 times) ⟹ S = 5050
When d is known
Sₙ = (n/2) [ 2a + (n - 1)d ]
Standard sum formula for any AP
When last term l is known
Sₙ = (n/2) (a + l)
For first n positive integers: n(n + 1)/2

NCERT Page 66 • Example 13 Deep Dive

The Double Solution Paradox: n = 4 and n = 13

How many terms of the AP: 24, 21, 18, … give a sum of 78? We get two values: n = 4 and n = 13. Why are both admissible?

Algebraic Solving

Sₙ = 78 = (n/2)[ 48 + (n - 1)(-3) ]
78 = (n/2)[ 51 - 3n ] ⟹ 3n² - 51n + 156 = 0
n² - 17n + 52 = 0 ⟹ (n - 4)(n - 13) = 0
⟹ n = 4 or n = 13

The Mathematical Reason

Let us write out the terms from 1 to 13:

First 4 terms: 24 + 21 + 18 + 15 = 78
Terms 5 to 13: 12, 9, 6, 3, 0, -3, -6, -9, -12
Sum of terms 5 to 13 = 0 (They cancel out!)
Because positive terms cancel out negative terms, the total sum stays 78!

Real-World AP: Semicircle Spiral & Log Stacking

Real life geometric shapes and physical arrangements follow arithmetic progressions!

Spiral of 13 Semicircles (Fig 5.4)

Radii: 0.5, 1.0, 1.5, 2.0 … cm. Length of semicircle = π r.

Lengths form AP: 0.5π, 1.0π, 1.5π, ...
a = 0.5π, d = 0.5π, n = 13
Total Length = (13/2) [ 2(0.5π) + 12(0.5π) ] = (13/2)(7π)
= (13/2) × 7 × (22/7) = 143 cm!

200 Logs Stacked (Fig 5.5)

20 logs bottom row, 19 next, 18 next... Total = 200 logs.

a = 20, d = -1, Sₙ = 200
200 = (n/2)[ 40 - (n - 1) ] ⟹ n² - 41n + 400 = 0
(n - 16)(n - 25) = 0 ⟹ n = 16 rows
Logs in top row = a₁₆ = 20 - 15 = 5 logs!
NCERT Section 5.5 • Summary

Arithmetic Mean & Chapter Summary

If a, b, c are three consecutive terms in AP, then b = (a + c) / 2. The number b is called the Arithmetic Mean of a and c.

Concept Formula Meaning & Key Usage
Common Difference d = aₖ₊₁ - aₖ Can be positive, negative, or zero
n-th Term aₙ = a + (n - 1)d Also represents the last term l
Sum of n Terms Sₙ = (n/2)[2a + (n - 1)d] Total accumulation of n terms
Sum with Last Term Sₙ = (n/2)(a + l) Fast calculation when l is known
Term from Sums aₙ = Sₙ - Sₙ₋₁ Finding n-th term when Sₙ is given
